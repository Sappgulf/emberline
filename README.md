# Emberline

Dusk woodland tower defense. Hold four maps. Plant six towers on the grass beside the road.

## Play

```bash
npm install
npm run dev
```

Open `http://localhost:8080`.

## Watch

- **Towers:** Longbow, Mortar, Frost, Spark, Bramble, Ash Ward
- **Forms:** Timber → Bound → Tempered → Crowned → Emberlit
- **Tools:** Horn (burn + slow), Mend (lives + drag), Move, Sell
- **Relics** persist between maps. Stall prices drop each wave.

## Stack

TanStack Start, React, Canvas 2D.
